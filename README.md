# hello_world

Flutter 计数器示例应用，支持 Web 端与 Android 模拟器运行。

## 运行方式

确保已安装 Flutter SDK 并配置好环境变量。

### Web 端
通过使用

flutter run -d chrome
来进行打开并运行web端


### Android 

注意：需要插件的下载

```bash
flutter devices        # 查看可用设备
flutter run -d emulator-5554   # 替换为模拟器 ID
```
